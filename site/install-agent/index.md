# Install Trackify with a coding agent

Status: pre-release

Trackify does not have an installable V1 release yet. Do not download or execute unofficial binaries or scripts claiming to install it.

The future stable agent-installation protocol will live at this URL. It will provide:

- The current signed release-manifest URL.
- Supported macOS versions and architectures.
- Artifact checksums, expected Apple Team ID, and bundle identifiers.
- Exact verification, installation, bootstrap, repair, and rollback steps.
- Clear macOS-permission and provider-login boundaries.

Until V1 is published, follow development in the [public repository](https://github.com/vucinatim/trackify) and read the [installation design](https://github.com/vucinatim/trackify/blob/main/docs/INSTALLATION.md).
